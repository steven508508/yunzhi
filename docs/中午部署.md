> 版本 **v0.22.0**　｜　2026-07-29

## 這次部署的是什麼

**完整的一條動線，從一份紙本題本到學生的成績單：**

```
上傳題本（PDF／掃描／手機拍）
   → AI 讀整頁、抽出題目與答案
   → 老師在校對介面逐題確認（數學式與化學式現在排得出來）
   → 寫進題庫
   → 挑題組卷
   → 派給班級或指定學生
   → 學生線上作答（隨機題序、伺服器計時、斷線不掉答案）
   → 交卷自動計分
   → 老師看全班成績與各題答對率
   → 學生看自己的分數、逐題檢討與解析
```

加上讓它跑得起來的周邊：班級與名冊（CSV 匯入，讀得懂 Excel 存的 Big5）、
知識點圖譜、學年度、帳號／家長同意／密碼重設、以及資料庫層的租戶隔離。

**v0.20.0 上線了學生端**（在那之前學生登入只看到「學生端還在開發中」），
**v0.21.0 補上三個「裝起來就是死路」的缺口**（科目、教職員帳號、授課指派），
**v0.22.0 是六份真實使用情境模擬之後的整修**——扮演裝機的主任、建題庫的
老師、出卷的老師、應考的學生、考試當天處理狀況的人、以及開學三個月後的
維護者，各自從頭走一遍，找出 113 個卡點、34 個阻斷，逐一修掉。
報告留在 `docs/情境-*.md`。

## 部署步驟

```bash
git clone <你的 repo> yunzhi && cd yunzhi
# 不要 checkout 到某個舊標籤。clone 拿到的預設分支就是最新版，
# 而舊版少的往往不是「一個功能」而是整條動線：v0.20.0 沒有科目、
# 沒有教職員帳號、沒有授課指派，裝出來是一個開箱即用不了的空殼。
cat VERSION                 # 確認版本，應該是 0.22.0 或更新

cp .env.example .env
chmod 600 .env          # 裡面有資料庫密碼與備份金鑰
$EDITOR .env            # 見下一節

./deploy/scripts/docker-install.sh
```

安裝腳本會依序做：建立設定 → 安裝前檢查 → 建置映像 → 起相依服務 →
跑遷移 → 起應用 → 驗收。

Ubuntu 從零開始（沒裝 Docker、要設開機自動啟動）走
`sudo ./deploy/scripts/ubuntu-install.sh`，手冊是 `docs/UBUNTU.md`。
它處理 Docker 安裝、docker 群組、cgroup 記憶體控制器、時區與語系、
ufw（**Docker 會繞過 ufw**）、開機自動啟動。

## .env 一定要改的六項

| 變數 | 說明 |
|---|---|
| `APP_DOMAIN` | 對外網域。**少了它 web 會在第一次上傳題本時整個掛掉**，而且容器看起來是健康的 |
| `APP_URL` | 完整網址，含 https:// |
| `AUTH_SECRET` | `openssl rand -base64 48` |
| `POSTGRES_PASSWORD` | 同上產生 |
| `BACKUP_ENCRYPTION_KEY` | 同上產生。**弄丟就還原不了備份** |
| `AI_*` | 見下一節 |

其餘用 `deploy/scripts/gen-secrets.sh` 產生即可。

## AI 端點的設定

```bash
AI_PROVIDER=openai
AI_BASE_URL=https://你的閘道網域/v1     # 結尾的 /v1 不能省
AI_API_KEY=<你的金鑰>
AI_MODEL_HIGH=gpt-5.6-sol
AI_MODEL_MID=gpt-5.6-sol
AI_MODEL_LIGHT=gpt-5.6-sol
AI_MONTHLY_TOKEN_BUDGET=0               # 0 = 不限。先觀察一個月再訂
```

**部署完成後第一件事，跑預檢**（三十秒、幾乎不花錢）：

```bash
docker compose exec ai python3 /app/../tools/ai-preflight.py
# 或在 repo 根目錄，設好上面那些環境變數之後：
python3 tools/ai-preflight.py
```

它問四個問題，其中**「看得懂圖嗎」決定整個匯入模組成不成立**——
這條管線是「模型讀整頁影像」設計的。過了再跑
`python3 tools/verify-ai.py --pages 6` 拿真實講義量準確率。

第三方相容閘道對參數的要求互相矛盾（新一代模型只吃
`max_completion_tokens`、推理模型拒絕自訂 `temperature`），
系統會自動協商，你不必知道你的閘道屬於哪一種。

## 第一次登入之後的順序

系統首頁會依「擋住後面所有事的排最前面」列出待辦。照著做就對了：

1. **建立學年度**（`/settings/years`）——班級要掛在它底下，沒有它建不了班
2. **開班、匯入名冊**（`/classes`）——CSV 直接丟，Excel 存的 Big5 讀得懂
3. **登錄家長同意**——名冊建出來的帳號是停用的（個資法第 15 條），
   在名冊頁逐一按「登錄同意」才會啟用
4. **建知識點**（`/knowledge`）——**這一步不做，匯入的自動標註等於沒有作用**。
   建議先只做數學 A，每科約 4 到 8 小時的老師工時
5. **匯入第一份題本**（`/import/new`）
6. **組一份卷子**（`/papers`）→ **派出去**（`/assignments`）→
   學生在 `/take` 作答 → 老師在 `/grades` 看結果

## 上線第一天會遇到的三件事

**一、名冊匯入建議分班做，不要一次丟 200 人。**
每一個新帳號都要算一次密碼雜湊（bcrypt 12 輪，約 0.35 秒），
200 人大約要等一分鐘，畫面會停著。一班 30 人約 10 秒。
試算畫面在超過 40 人時會先告訴你大概要等多久，那段時間**不要重新
整理也不要重複按**（重按不會建出重複帳號，但你會以為失敗了）。

**二、家長同意可以整批做，也可以寫在名冊 CSV 裡。**
名冊匯進來的帳號預設是停用的（個資法第 15 條），要登錄家長同意才啟用。
CSV 多一欄「家長同意」（填「紙本」「現場」「線上」或「是」）就在匯入時
一起完成；已經匯進來的可以在名冊頁勾選批次登錄。**不要一位一位按**——
200 位大約是半小時。

**三、忘記密碼在名冊頁重設。**
沒有寄信功能（這些學生多半沒登記 email，機房也連不出去）。
實際流程就是學生跟老師講、老師在名冊上按「重設密碼」，畫面會顯示
一組新密碼——**那串字只出現一次，關掉就沒有了**，請當場抄給學生。
學生登入後可以在 `/settings/password` 自己改。

**四、派卷之前確認授課老師名單。**
老師只派得了「自己教的科目 × 自己教的班」。這個檢查看的是
`class_subject_teachers` 那張表。如果某位老師實際教三個班而資料只
建了一列，他派另外兩班時會被擋下來（錯誤訊息會指名是哪個班）。
**開學前抽查一下那張表**，比當天現場處理省事。

## 已知的限制（不是 bug，是還沒做）

**家長端沒有。** 家長帳號建得起來、登得進去，但登進去只會看到
「家長端還在開發中」。

**線上作答的題目裡還沒有圖。** 校對介面與紙本考卷已經看得到附圖，
但學生的作答畫面上還沒接（題幹中間會出現 `![[a:fig1]]` 標記）。
數學式與化學式在每一個畫面都排得出來（KaTeX + mhchem，字型打包在
映像裡，不連外部 CDN）。

**含作文的卷子要老師手動給分。** 非選題會標成待評分，老師在成績頁
逐題輸入（重算不會蓋掉手動分數）。AI 閱卷還沒做。

**沒有能力分析與智慧老師。** 這兩項是願景裡的核心，還沒開始。

**建置機器需要能連 Docker Hub 與 binaries.prisma.sh。** Prisma 的查詢
引擎是執行期的硬相依，建置時會下載並烤進映像。企業防火牆很常放行
前者卻擋掉後者，而那會讓建置在第 8 分鐘才失敗；`preflight.sh` 現在
會分開測這兩個目標。機房完全封閉時走離線包：
`./deploy/scripts/build-offline-bundle.sh` 在有網路的同架構機器上打包，
搬過去之後 `sudo ./deploy/scripts/ubuntu-install.sh --offline`。

## 出事的時候

```bash
docker compose ps                       # 誰沒起來
docker compose logs -f web --tail=100   # 應用日誌
curl localhost:3000/api/readyz          # 依賴檢查（第一次可能 503，等 40 秒）
curl localhost:3000/api/version         # 現在跑的是哪一版

./deploy/scripts/doctor.sh              # 一次跑完所有健檢
./deploy/scripts/rollback.sh            # 回到上一版（含資料庫）
```

**回滾之前先看 `/api/version`**，確認你要回的版本號。升級腳本用
`VERSION` 檔當映像標籤，版本對不上的話會回到錯的地方。

考試當天最可能需要的兩個動作，都在 `/grades/<任務>` 那一頁：

- **有人斷線沒交卷**：時間到之後那一份會卡在「進行中」，學生端顯示
  已完成卻沒有分數，老師端整個人不出現。那一頁的「未完成的作答」
  可以代為結算。
- **抓到作弊或機器壞掉**：學生列表上可以「作廢」那一份（要填理由，
  進稽核），作廢不佔作答次數，可以讓他重考。誤判可以撤銷。
